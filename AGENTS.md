# Agent build rules for this repository

Before creating or modifying student-facing HTML, Apps Script, save/resume behavior, or PDFs, read [CLASSROOM_HTML_SAVE_PDF_STANDARD.md](CLASSROOM_HTML_SAVE_PDF_STANDARD.md) and apply its release gates. The same standard is intended for U.S. History and Personal Finance.

Do not modify live save code or existing student data without explicit teacher authorization. Never claim cloud-save verification, a working image, or a verified PDF without actual testing. Preserve the exact teacher-supplied Apps Script deployment URL. All student-facing text needs generous Tier 2/3 hover/tap/focus definitions, and every text box needs two unlabeled sentence frames. Every exported PDF displays the completion grade prominently at the top. The student UI contains three main actions: Save now, Download Assignment PDF, Emergency PDF.
